# v1.0.0 原型说明（对标 Display_Wall）

## 品质标准对齐

本版本指挥大屏对标 `海南/Display_Wall`（武穴样板）：

| 标准项 | 要求 | 本版落地 |
|---|---|---|
| 比例自适应 | 整屏无滚动、等比铺满 | 16:9 `aspect-ratio` |
| 视觉体系 | 深蓝政务科技风 | `#051838` / `#0E74F0` / `#00E4FF` |
| 组件 | 卡片、角标、顶线、半透明面板 | 已实现 |
| 指标 | 翻牌数字 + KPI 卡 | 已实现 |
| 图表 | ECharts 折线/条形 | 本地 `vendor/echarts.min.js` |
| 地图中枢 | 底图 + POI 下钻 | `assets/port-map.png` + 详情浮层 |
| 离线可开 | 无外网依赖 | vendor 本地化 |
| 拼接能力 | 模块可拖 | 编排模式 + 模块库 |

## 打开方式

1. 推荐：`pages/pc_wall_command_screen.html`
2. 版本入口：`index.html`
3. 总入口：`../../index.html`

## 与武穴差异（产品口径）

- 武穴：超长条双屏（约 15:3）
- 海南：兴盛 **16:9 单墙** + 5 逻辑分屏 + 模块拖拽
